# Getting help

Start with the [Docleus documentation](https://docleus.io) for installation,
configuration, daily workflows, and plugin development. Each repository's README
describes its scope, setup, and checks.

## Bugs

Open an issue in the repository that owns the behavior. If you are unsure where
it belongs, use the [distribution issue tracker](https://github.com/Docleus/docleus/issues).
Include reproduction steps, expected and actual behavior, the source revision
or image digest, relevant configuration, and logs with secrets removed.

## Ideas and contributions

Use a feature request to describe the problem and who it affects. Discuss large
or cross-repository changes before implementing them, and follow the
[contribution guide](CONTRIBUTING.md).

## Private reports

Follow [SECURITY.md](SECURITY.md) for vulnerabilities and
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) for conduct concerns. Keep exploit
details, credentials, private data, and conduct reports out of public issues.

The project is preparing its first public preview. Support is community-led;
there is no guaranteed response time or stable-release maintenance window yet.
