## Built around your documentation

| Write                                       | Review                                         | Publish                                         |
| ------------------------------------------- | ---------------------------------------------- | ----------------------------------------------- |
| A block editor with real-time collaboration | Draft branches, approvals, and change requests | Versioned sites with rollback and static export |

Run with SQLite and local files, or Postgres and S3-compatible storage. Extend
the platform through the same public TypeScript SDK used by official plugins.

experimental before 1.0. Packages are currently built from side-by-side source
checkouts rather than installed from npm. Every repository is MIT licensed.
